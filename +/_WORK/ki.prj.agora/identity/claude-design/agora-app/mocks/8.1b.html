ki-agentic-harness/skills/governance/ki-delegation

Govern agent delegation: routine detached background runs (run packet, prompt shape, authority footers, decisions log, coordination, run queue, monitoring) and durable packets for approved high-risk handoffs.

When to use it

When delegating to background agents or writing a delegation brief. ki agent launches runs, and ki-coordination governs the coordinating work that launches them.

The run packet

Every detached run carries its packet: what to do, the authority it holds, where it reports, and the footer it ends with. See references/standards-background-runs.md.
