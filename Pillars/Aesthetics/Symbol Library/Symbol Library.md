# Symbol Library

## Overview

The Symbol Library is the canonical reference for the visual symbols used across Knowledge Islands outputs. Each symbol carries a defined conceptual meaning drawn from the geographic metaphor at the heart of the model - and must be used consistently so that viewers build reliable associations across diagrams, interfaces, presentations, and communications.

The library provides two layers of asset: a reference sheet mapping symbols to their meanings, and a set of standalone illustrations for use in documents and interfaces.

For the full symbolic semantics table and terrain language, see [[Visual Style/Visual Style|Visual Style]].

## Symbols

The eighteen canonical symbols, their meanings, and terrain associations:

| Symbol            | Meaning                       |
| ----------------- | ----------------------------- |
| Island            | Domain of knowledge           |
| Archipelago       | Federated knowledge ecosystem |
| Port              | Entry and exit; integration   |
| Lighthouse        | Guidance                      |
| Council Hall      | Governance                    |
| Citadel           | Civic heart of a Capital      |
| Tower             | Watching and guiding          |
| Observatory       | Insight / analytics           |
| Route             | Relationship                  |
| Current           | Information flow              |
| Bridge            | Translation layer             |
| Reef              | Risk / ambiguity              |
| Terrain           | Depth / maturity              |
| Ancient Forest    | Wisdom / continuity           |
| Weave / Fabric    | Cross-domain synthesis        |
| Cartographic Grid | Structure / orientation       |
| Celestial Guide   | Long-range orientation        |
| Trade Route       | Collaboration / exchange      |

The Port replaced the Harbour, and the Lighthouse and Council Hall took separate meanings, under [[GDR-KI-PRINCIPAL-010-the-port|GDR-KI-PRINCIPAL-010]]. The Harbour is retired as a symbol; operational systems, the old Port meaning, belong to `Admin/Operations`.

The Citadel and the Tower were confirmed under [[GDR-KI-PRINCIPAL-011-the-citadel-and-the-tower|GDR-KI-PRINCIPAL-011]]. The Citadel holds the Library, the Council Hall and the Tower, and is drawn across a 7-hex flower. The Tower is the mark of the local app, the Observatory; the domed Observatory symbol keeps its meaning of insight and is never the app's mark.

### Port modes

A Port has four modes, each drawn as a district of one Port:

| Mode          | Meaning                                                  |
| ------------- | -------------------------------------------------------- |
| Dock          | By sea; exchange with other islands, material carried in |
| Rail depot    | Scheduled, high-volume flows along fixed lines           |
| Airport       | Fast, long-range connections to distant lands            |
| Customs house | Where what enters or leaves is inspected and declared    |
