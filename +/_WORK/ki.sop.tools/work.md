# ki.sop.tools

## Goals

- Keep the island's tools and MCP servers working, released and accounted for, as the quartermaster of the territory the [Charter](/Users/krisbrown/kis/knowledge-islands/ki-principal/Admin/Governance/Charter.md) declares, from a secondary State of play under ki.sop.main.

## Scope

- In: tool and MCP server faults and fixes, releases prepared for Kris, and the account of which tools exist, where they run and at what version.
- Out: deciding how a tool must behave, which is the guild's (ki.reg.guilds); heading the territory, which is ki.sop.main's; releasing anything without Kris; work no `covers` entry assigns here, which stays with ki.sop.main.
