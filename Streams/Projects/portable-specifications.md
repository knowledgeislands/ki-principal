# Portable specifications

## Outcome

Draft, home and publish three portable specifications: `work`, a package of work without the house ways of working; `knowledge`, a well-curated package of knowledge whose description says what it teaches; and `acquire`, how knowledge is acquired, such as through a particular tool. Each follows the agentskills.io specification's conventions and works by progressive disclosure. Each is held as one reference in its owning harness skill, `ki-work-package` for `work`, `ki-acquire` for `acquire` and a new skill for `knowledge`, published later from the same text on the Knowledge Islands website, and handed to KI Specifications when it opens v1. The move depends on KI Specifications restarting, which this Project does not control.

This Project sits in [Model](../Themes/model.md). Kris opened it on 19 October 2026 as `specifications` and renamed it under PROJECT-NAME the same day, keeping the paused [specifications](specifications.md) Project as it is. Its work is [ki.portable-specifications](<../../+/_WORK/ki.prj.portable-specifications/work.md>).
