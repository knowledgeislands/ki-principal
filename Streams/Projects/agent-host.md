# Agent Host

## Outcome

Move agent work into the Techne footprint on an agent host, one of the two hosts the [Techne Programme Focus](<../../Admin/Governance/Policies/Techne Programme Focus.md>) keeps in scope. Agent hosts are harness-defined recipes that a person binds into named instances, and the prototype review kept the host.

This Project sits in [Techne](../Themes/techne.md). It and [baseline-rollout](baseline-rollout.md) do not gate each other.

[Hosts, Roles and Layers](<../../Pillars/Engineering Practice/Architecture/Hosts, Roles and Layers.md>) explains how a host is built in layers and which role `vega` plays.

## Notes

Paperclip, Kitteth, Telegram, wider K3s, the controller and every other environment are kept as ideas.
- **Model.** `agent-host` is the first recipe, and its first binding, rendered by chezmoi into `~/.config/techne/`, shares the name. [ADR-KI-PRINCIPAL-006](../../Admin/Governance/Decisions/ADR-KI-PRINCIPAL-006-techne-implementation-ownership.md) records the ownership split.
- **Durability.** [ODR-KI-PRINCIPAL-001](../../Admin/Governance/Decisions/ODR-KI-PRINCIPAL-001-keeping-work-safe-on-the-agent-host.md) decides how work on the host stays safe: a structured status verdict, stop that warns, guarded rebuild and withdraw, declared pins, an expiry view, the operator's workstation as the roadmap writing checkout, and the two-checkout rule.
- **Identity and egress.** The host's GitHub token and Claude login are the binding owner's own until unattended agents arrive. The security group allows TCP 443 and 80 to any address; named-destination egress is still open.
- **Durability rollout.** Every [ODR-KI-PRINCIPAL-001](../../Admin/Governance/Decisions/ODR-KI-PRINCIPAL-001-keeping-work-safe-on-the-agent-host.md) record is captured in its owning repository: the guarded-work pilot and the pins-and-expiries record in `ki-techne-harness`, guarded host commands in `tools-techne`, the recipe's own two-checkout and writing-checkout instructions for Claude and Codex in the pins-and-expiries record, Kris's personal wording of the rule in the chezmoi source, the `ki` refusal of roadmap writes on the host marker in `tools-ki`, and a non-blocking handoff on where a writing-checkout designation lives in `ki-agentic-harness`. The pins-and-expiries record also removes the review date from host status. The guarded-work pilot and the pins-and-expiries record are delivered, accepted and live: the 2026-10-08 setup run found every repository safe, no pin drift and a silent banner. A 2026-10-09 setup rerun took up the raised `ki` pin with no drift.
