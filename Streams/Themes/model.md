# Model

## Direction

The Model is a theme because the idea of a Knowledge Island runs under almost everything the territory does: what an island is, how it is tended, how islands trade with one another, how outside knowledge comes in, how the model is specified and how it is presented to others. What matters most is that the model stays one coherent account, written down in the Capital's [Philosophy](../../Pillars/Philosophy/Philosophy.md) and enforced by the harness standards, so that every island can be read and checked the same way.

Knowledge Islands Principal, as Capital, owns most of the work under this theme. Work under it changes canonical content through the [Enactment Process](<../../Admin/Operations/Processes/Enactment Process.md>), keeps the work model in the [Work Process](<../../Pillars/Philosophy/Model/Processes/Work Process/Work Process.md>) note as its single description, and records lasting choices as Decision Records, such as [ADR-KI-PRINCIPAL-002](../../Admin/Governance/Decisions/ADR-KI-PRINCIPAL-002-territory-derived-repository-selection.md) for territory-derived repository selection. The tooling that checks and serves islands belongs to [Foundations](foundations.md).
