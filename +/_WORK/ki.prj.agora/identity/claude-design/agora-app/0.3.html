0.3 · Atlas shell

The frame every page of Agora Atlas sits in, now that the app holds far more than the first pack drew: the map, the work (Roadmap, Jobs), the guilds, the Observatory's instruments, the KIV's pages, accounts, settings and updates. It replaces the rail of 0.1. It matters because each page so far brought its own tray, pane and filters; one shell with fixed places for navigation, context, detail and documents lets Kris learn the window once, and lets the Roadmap, Jobs and Guilds designers build on the same frame (atlas_page in build/mocks.py; IA.md has the rules).

Refreshed 2026-11-06 · source: mock-ups from build/plan.py; not yet built

What it shows
  • Toolbar (N1): Agora Atlas, the rigs, one word on the whole, the search, Mark all, Away…, Broadcast…, the time, pin and theme
  • Sidebar groups (N2): Agora, Work, Guilds, Observatory, KIV (folded while it is coming), Coming; a count only where something waits
  • Sidebar foot (N3): Accounts, Settings, Updates; the portal between the rigs; Beacon in the menu bar and Lantern on the iPhone
  • Tabs (N4): the place or document in each tab; a sidebar click replaces the current tab, ⌘-click opens a new one
  • Context (C1), top right: the territory and the plane for every page that reads them; greyed, not hidden, where a page ignores one
  • Page (P): the page header and its content, which the page owns
  • Right tray (T1): the facts of one selected thing; it pushes the page narrower and closes with × or Escape
  • Bottom pane (B1): the selected thing's documents or long readings, in tabs; drag its top edge to resize

Region codes: B, the bottom pane (green); C, the context control (slate); N, navigation (teal); P, page content (brass); T, the tray (blue). Quote them as "0.3a P2".
