# Orca Evaluation

## Outcome

Kris knows how best to use Orca alongside Knowledge Islands - what it does well, where it fits the work model and where it does not - with that knowledge built up in the island as the evaluation goes. Orca is assessed as the live layer (launch, worktrees, task queue, heartbeats and gates) beside Knowledge Islands as the durable layer (work package, roadmap, authority and decisions), without forcing Orca off what it does best. The test: Kris has a settled way of using Orca, and what was learnt has a durable home in the island.

This Project sits in [Techne](../Themes/techne.md), beside [delta-evaluation](delta-evaluation.md) and [paperclip-capture-and-rebuild](paperclip-capture-and-rebuild.md), because it is about running governed agent work on the Mac Studio.
