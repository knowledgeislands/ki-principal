# Themes

## Overview

This folder holds the Knowledge Islands territory's themes, the long-lived directions its work serves, held by Knowledge Islands Principal as Capital beside the [[Projects]] that name them. A theme is a label, not a level: it holds no work and never finishes. Each page is named by its slug, so a Project's, work record's or Activity's `theme` value resolves to a path here.

Links point upwards only: a Project, record or Activity names its theme, and a theme page carries its direction and notes but lists no Projects, records or Activities. Status lives in each record and `ki` produces the views. Membership is classification, not authority: each owning repository keeps its plan, priority and acceptance.
